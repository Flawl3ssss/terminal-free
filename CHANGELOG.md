# Changelog

## 1.3.0

- Клавиатура: тап по терминалу теперь поднимает мягкую клавиатуру (раньше
  тап по приглашению `root@localhost:/workspace#` распознавался как «ссылка-
  путь» и не поднимал IME; показ делался и через несколько стратегий с
  ретраями, т.к. часть прошивок молча игнорирует `showSoftInput` сразу после
  смены фокуса). Плюс плавающая кнопка ⌨ в правом нижнем углу — показать/
  скрыть клавиатуру (Back в терминале отдаётся на ESC, поэтому кнопка
  обязательна); состояние отслеживается по window insets.
- Back при открытой клавиатуре сначала закрывает её, а не уходит в ESC.
- CTRL/ALT в панели extra keys теперь защёлкиваются: нажал — модификатор
  держится до следующего нажатия или до ввода символа (авто-сброс после
  кодовой точки). Раньше один тап переключал latch туда-обратно: тач-случатель
  возвращал `false`, из-за чего `performClick()` выстреливал дважды — CTRL/ALT
  включался и тут же выключался, а ESC/TAB/`&&` отправлялись дважды.
- Меню сессий: строки списка увеличены (имя 15sp, отступы 14/12), крестик
  закрытия получил нормальную цель 44 dp с ripple вместо 12 dp — по нему
  теперь реально попасть; единственная сессия не закрывается случайным тапом
  (показывается подсказка вместо молчаливого «ничего не произошло»).
- Браузер переписан: строка прогресса загрузки, кнопки вперёд/назад с
  состоянием, переключение ⟳/■ (reload/stop), поиск по странице (счётчик
  «текущий/всего», вверх-вниз, закрытие), «Поделиться» ссылкой, «Home»,
  выбор файлов для `<input type=file>` и сообщение об ошибке загрузки.
- **Настоящее масштабирование страницы**: кнопки `− / % / +` меняют
  `WebSettings.textZoom` (переполнение текста на новый размер, а не попиксельный
  зум вьюпорта), значение сохраняется между запусками, тап по `%` сбрасывает в
  100%. Пинч-зум оставлен отдельно и не мешает.
- Ввод в адресную строку без схемы понимается как адрес (точка есть) или как
  поисковый запрос (пробел/без точки → DuckDuckGo).
- Меньше места на диске (≈3 GB → ≈1 GB):
  - rootfs собирается без мусора apt: `--no-install-recommends`,
    `/var/lib/apt/lists` (150 MB), `pkgcache.bin`/`srcpkgcache.bin` (109 MB),
    кэш `.deb` (13 MB), `/usr/share/{doc,man,info,lintian,bug}`, логи и
    `/var/tmp` вычищаются на сборке (вариант 2);
  - в контейнере появляется `/etc/apt/apt.conf.d/99tf-slim` (без
    рекомендаций/предложений, без переводов, без кэша пакетов) — apt больше
    не раздувается обратно (вариант 1);
  - разовый чистильщик при первом старте новой версии: apt-кэши, man/doc,
    `/root/.npm`, `/root/.cache`, обрезка Node (`share`, `include`, corepack,
    docs/man/test npm) — включая кэш npm от установки 522 пакетов dsh;
  - из пакетов dsh-тулчейна убран `python3-pip` (~40 MB); `openssh-client`
    оставлен (нужен для `git clone git@…`). Вернуть: `apt install python3-pip`;
  - скачанный `rootfs-*.tar.xz` (93 MB) удаляется сразу после установки или
    сброса, старые кэши чистятся при каждом запуске приложения.

## 1.2.0

- Файловый менеджер показывает ВСЕ папки и файлы устройства напрямую:
  приложение запрашивает системный доступ «ко всем файлам» («All files
  access» на Android 11+, чтение/запись на более старых версиях), без
  SAF-пикера и выбора папки. Корневой экран — внутреннее хранилище и SD-карты.
- Импорт из устройства в `/workspace` и экспорт из `/workspace` на устройство
  идут обычным копированием `java.io.File`; кнопка в настройках dsh теперь
  показывает/выдаёт полный доступ к файлам.
- Изоляция контейнера сохранена: proot по-прежнему не монтирует ни один путь
  файловой системы устройства.
- Исправлена критическая ошибка первой установки: распаковка rootfs теперь
  корректно обрабатывает хардлинки из tar (раньше `/usr/bin/env`, `perl` и все
  утилиты rust-coreutils записывались пустыми файлами → «Exec format error»,
  сломанные postinst в dpkg). Старые сломанные установки чинятся автоматически
  при следующем старте сессии (repair при запуске терминала).
- Первый запуск стал терпимее: `DEBIAN_FRONTEND=noninteractive`,
  `dpkg --configure -a` до и после установки пакетов, установка dsh с фоллбэком
  `node npm-cli.js`, если `npm`-скрипт не запускается.

## 1.1.0

- DeepSeek Harness (dsh): автоматическая установка при первом запуске
  терминала (пакеты, Node.js 22, dsh), ключ API в настройках,
  Web-интерфейс dsh во встроенном браузере.
- Рабочая область `/workspace` (хост-папка `filesDir/workspace`, биндится
  в контейнер), `DSH_HOME=/workspace/.dsh`.
- Экран «Files» (двусторонний мост device ↔ workspace), встроенный браузер
  со зумом, обновление dsh в одну кнопку с бэкапом и откатом.

## 1.0.0

- Первый релиз Terminal Free на базе RedTerm 2.0.0 (GPL-3.0).
- Изолированный proot Ubuntu 26.04 LTS (arm64): контейнер не монтирует
  `/sdcard`, `/storage`, `/mnt`, `/data`; приложение не запрашивает
  разрешений на хранилище и медиа.
- Оптимизированная работа в фоне: тихий сервис по умолчанию (без уведомлений),
  полное завершение всех процессов при свайпе из списка задач, опциональный
  фоновый режим с уведомлением.
- Сборка APK и rootfs через GitHub Actions.
