# Changelog

## 1.2.0

- Файловый менеджер показывает ВСЕ папки и файлы устройства напрямую:
  приложение запрашивает системный доступ «ко всем файлам» («All files
  access» на Android 11+, чтение/запись на более старых версиях), без
  SAF-пикера и выбора папки. Корневой экран — внутреннее хранилище и SD-карты.
- Импорт из устройства в `/workspace` и экспорт из `/workspace` на устройство
  идут обычным копированием `java.io.File`; кнопка в настройках dsh теперь
  показывает/выдаёт полный доступ к файлам.
- Изоляция контейнера сохранена: proot по-прежнему не монтирует ни один путь
  файловой системы устройства.
- Исправлена критическая ошибка первой установки: распаковка rootfs теперь
  корректно обрабатывает хардлинки из tar (раньше `/usr/bin/env`, `perl` и все
  утилиты rust-coreutils записывались пустыми файлами → «Exec format error»,
  сломанные postinst в dpkg). Старые сломанные установки чинятся автоматически
  при следующем старте сессии (repair при запуске терминала).
- Первый запуск стал терпимее: `DEBIAN_FRONTEND=noninteractive`,
  `dpkg --configure -a` до и после установки пакетов, установка dsh с фоллбэком
  `node npm-cli.js`, если `npm`-скрипт не запускается.

## 1.1.0

- DeepSeek Harness (dsh): автоматическая установка при первом запуске
  терминала (пакеты, Node.js 22, dsh), ключ API в настройках,
  Web-интерфейс dsh во встроенном браузере.
- Рабочая область `/workspace` (хост-папка `filesDir/workspace`, биндится
  в контейнер), `DSH_HOME=/workspace/.dsh`.
- Экран «Files» (двусторонний мост device ↔ workspace), встроенный браузер
  со зумом, обновление dsh в одну кнопку с бэкапом и откатом.

## 1.0.0

- Первый релиз Terminal Free на базе RedTerm 2.0.0 (GPL-3.0).
- Изолированный proot Ubuntu 26.04 LTS (arm64): контейнер не монтирует
  `/sdcard`, `/storage`, `/mnt`, `/data`; приложение не запрашивает
  разрешений на хранилище и медиа.
- Оптимизированная работа в фоне: тихий сервис по умолчанию (без уведомлений),
  полное завершение всех процессов при свайпе из списка задач, опциональный
  фоновый режим с уведомлением.
- Сборка APK и rootfs через GitHub Actions.
